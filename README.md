# Cooldown
Cooldown  A time budget for League of Legends.  You decide how much League you want this week while you’re thinking clearly. Cooldown holds you to it — gently, but reliably. It doesn’t lock you out: it ends the session when the budget is spent, and stops you from queueing back-to-back.  Status: early. Windows + League only for now. 

Principle

Don’t go over what you allocated to yourself.

Rational-you sets the budget. Emotional-you can’t overwrite it in the heat of the moment (if you configure it that way).

If you fail to control yourself: warn, or close everything and block access until the next budget arrives — your choice, set in advance.
